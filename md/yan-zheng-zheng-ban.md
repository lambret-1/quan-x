# 验证正版

QX允许**合理范围**内的共享使用，但是**禁止滥用**。

当前QX的授权验证方式为：

1、App Store 购买的 Quantumult X 可以与最多6位家庭成员或朋友共享。 如果此收据相关的iCloud用户数远超 6位，对于余下的 iCloud 用户（未在此列表中显示） Quantumult X的某些功能可能会被限制。

2、使用 iCloud 验证并无设备数量限制，即同一个iCloud下QX不限制设备数量。

3、设备数量无法靠登出自己当前的 iCloud 再登入别人已验证的 iCloud 来辅助验证，以当前设备第一次（或还原系统后第一次）启用的 iCloud 为准。

{% hint style="info" %}
注：可以美区 App Store 其他区域的 iCloud，以首次使用 Quantumult X 并开启 iCloud 功能的 iCloud 为准。
{% endhint %}

4、未登录iCloud时，限制8台设备。

5、QX的最新商店版已经支持了全系Mac，在Mac上对QX进行验证方法见下图：

### 查看方式

点开 QX app，点击右下角的风车图标进入设置页面，拉到最底下，选择其他设置，拉到最底下观察版本号旁边的云朵☁️状态：蓝色✓为正版，红色✕为盗版 / 共享版，绿色问号❔则表示无法验证，需要登陆购买的 Apple ID 进行再次验证。
